# Channel policy saves: live evidence for #1895

An isolated lane backend from this worktree (`make dev-be`, its own SQLite), the demo library
(`make demo-library` + `make demo-seed`, invented titles), and the Vite frontend (`make dev-fe`).
The filler jobs and channel maintenance were paused first. Chromium at 1440×1000, signed in as the
lane's dev admin.

Each run opens a seeded channel's Programming tab and types Era From, clicks To (the blur saves
From), types To and tabs out (the blur saves To) with no pause between. It waits four seconds,
screenshots, reloads, and screenshots again.

| Run | Channel | Typed | PATCH statuses | Saved after reload |
| --- | --- | --- | --- | --- |
| Before (parent commit's `route.tsx`) | Retro Rewind | 1980 → 1989 | 200, **409** | From 1980, To **empty** |
| After (this PR) | Premium 4K | 1990 → 1999 | 200, 200 | From 1990, To 1999 |

The channel API agreed with the page in both runs. Before: `dates` held only `{from: 1980}` on
each axis. After: `{from: 1990, to: 1999}` on each axis.
