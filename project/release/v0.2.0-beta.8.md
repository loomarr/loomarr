> **On-demand playout.** Channels now encode only while someone is watching, with spare capacity used
> to warm neighbouring channels so surfing stays quick. One channel packager keeps the programme and
> commercial timeline continuous, and resource-aware admission protects the server as viewers arrive
> and leave. Prepared, ahead-of-time media is gone.
>
> **Since beta.7:** rendition-aware neighbour warming that never promotes speculative work (#1811),
> faster warm channel changes on TV (#1792, #1798), 4K neighbours warmed in spare capacity (#1797),
> a retention index for finished process runs (#1812), VideoToolbox capability negotiation (#1806,
> #1808), Web player cleanup when surfing (#1805), and Web at phone width (#1785).
>
> **Migration 132 is forward-only.** Take a restorable backup of Loomarr's data directory before
> upgrading. Going back to an older image requires restoring that backup; changing the image alone
> is unsafe.
>
> **Known limitations:**
> - Performance targets were measured on the Intel Arc A380 reference install. Mac (VideoToolbox),
>   NVIDIA, software-only hosts and larger viewer counts are experimental, with every safety and
>   admission check still enabled. Mac and NVIDIA miss the strict startup/throughput benchmarks
>   (#1566, #1794).
> - Warm channel changes on Shield measured p95 1.1 s against a 600 ms target (#1037).
> - A long Shield soak on an earlier candidate recorded playback stalls that are not yet explained;
>   the 24-hour soak remains open (#1037).
> - Wider TV overlay and device qualification is open (#1781).
