## Loomarr v0.1.0-beta.1

The first public beta. Loomarr turns a sentence ("90s action movies, high energy, keep it PG-13")
into a self-maintaining virtual TV channel: a grounded LLM proposes a lineup from **your** library
and TMDB, you approve it, and Loomarr plays out a tuner + guide your media server picks up as Live
TV — with commercial pods, acquisition of missing titles via Seerr or Sonarr/Radarr, and
polling-driven backfill as they land.

**This is a beta.** It is meant for self-hosters comfortable with `docker compose`, reading a
README, and filing issues. Expect rough edges; do not run it as your only copy of anything you care
about.

### Who it's for

Technical self-hosters / homelab operators. You bring a media server (Emby or Jellyfin), optionally
Sonarr/Radarr/Seerr for acquisition, TMDB, and an LLM (Ollama or any OpenAI-compatible provider —
these are **prerequisites** for the channel-origination flow, not optional polish).

### Getting started

See the install docs (Quickstart, Docker, and the in-app Help). The short version: run the wizard,
connect your media server, describe a channel, approve it, and watch it in your guide.

### Known limitations

- **Single instance.** Loomarr is designed and tested as one replica. Running multiple replicas
  behind a load balancer is **not** a supported or verified configuration for this beta; treat any
  multi-replica behavior as undefined.
- **AI/TMDB are required for the core flow.** The only normal way to originate a channel is a
  grounded suggestion, which needs TMDB and an LLM configured. Without them the app runs, but the
  headline flow is unavailable — this is by design for the beta, not a bug.
- **`server.public_url` must be reachable by your media server** for internal-playout channels to
  tune. The wizard collects it and the backend warns at boot if it is unset; an env-only install
  that skips the wizard must set it, or channels appear in the guide and do not play.
- **Back up your data.** Loomarr's backup covers the **database only** — not the image volume
  (uploaded channel art) or the filler directory. Keep off-volume copies; see the upgrade docs.
- **Redistribution/licensing review is not complete.** The image bundles GPLv3+ ffmpeg (pinned by
  digest) and other third-party components; the exact GPL corresponding-source bundle and a final
  qualified legal/NOTICE review are still outstanding (see `THIRD_PARTY_NOTICES.md`). This beta is
  distributed on that understanding.
- **Hardware transcoding is auto-detected by trial**, not asserted. If your hardware is unusual, the
  probe may fall back to software encoding; watch the capacity/admission settings.

### Reporting problems

Please open an issue with your compose file (secrets redacted), the relevant container logs, and
what you expected versus what happened. Security issues: see `SECURITY.md` — do not open a public
issue.
